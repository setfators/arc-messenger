# Arc

Arc — мессенджер для своих: каналы, личные сообщения, друзья, голос и демонстрация экрана.
Работает прямо в браузере, сервер живёт на Cloudflare — включать домашний ПК не нужно.

**Живой адрес:** https://rust-messenger.sg530507.workers.dev

**Текущая версия:** 1.4.2 — сервер, клиент и десктоп-оболочка. Версия 1.4.2 — это
переименование приложения в Arc. Иконка приложения — прежняя, «пузырь с молнией».

## Быстрый старт

1. Откройте https://rust-messenger.sg530507.workers.dev и создайте аккаунт: имя 2–20 символов
   и пароль (не короче 4 символов).
2. Разрешите уведомления, когда браузер спросит, — иначе не будет всплывающих сообщений и звука.
3. Для голоса разрешите микрофон: браузер спросит при первом входе в голосовой канал.
4. Установите как приложение: в Chrome/Edge — «Установить приложение» в адресной строке
   или меню браузера, на телефоне — «Добавить на главный экран». Откроется без адресной строки.
5. Позовите друга: значок 👥 → «Друзья» → имя → «Добавить»; свой канал — «+ создать канал».

## Возможности

**Чаты и каналы**
- каналы в левой панели, `#obshiy` по умолчанию, свои каналы создаются и удаляются;
- личные сообщения: диалоги в списке, переписку можно убрать из списка;
- история канала — последние 300 сообщений, переживает перезапуск;
- «печатает…», счётчики непрочитанных и уведомления, счётчик в заголовке вкладки;
- удаление своих сообщений;
- ответы (цитаты): в сообщении `replyTo`, в ленте — компактная цитата над текстом,
  клик по ней прокручивает к оригиналу и подсвечивает его;
- реакции: быстрый набор из 6 эмодзи кнопкой «+» на сообщении, повторный клик снимает;
- картинки в чате: скрепка, drag&drop и вставка из буфера, до 2,5 МБ, сжатие до 1600px,
  просмотр в лайтбоксе;
- поиск по истории — по каналам и своим личкам, от 2 символов, до 40 попаданий;
- фоновые уведомления (Web Push) при закрытом приложении.

**Друзья и приватность**
- заявки в друзья, список друзей, удаление из друзей;
- поиск людей по имени и карточка пользователя — по клику на имя или аватар;
- личка «только от друзей» — проверяется на сервере, а не только в интерфейсе;
- статусы: в сети, не активен, не беспокоить, невидимка.

**Роли и модерация**
- три роли: **владелец**, **сотрудники** (модераторы) и участники;
- владелец выдаёт коды-приглашения, назначает сотрудников, банит, удаляет каналы
  и может открыть регистрацию для всех;
- сотрудники удаляют любые сообщения и выдают мьют (10 минут / 1 час / 6 часов / сутки);
- бан закрывает все сессии и не пускает ни вход, ни WebSocket; разбан возвращает доступ;
- замьюченный видит, на сколько ему запрещено писать, и не может отправить сообщение;
- экспорт базы в JSON для резервной копии (без паролей и токенов) — только владельцу.

**Аккаунт и безопасность**
- смена пароля с проверкой старого;
- выход на всех других устройствах;
- удаление аккаунта с подтверждением паролем — вместе с сообщениями и вложениями;
- строка версии приложения в настройках.

**Голос и экран** — голосовой канал по WebRTC до 8 человек (у каждого своя громкость)
и демонстрация экрана в канале.

**Профиль и оформление**
- отображаемое имя, био, акцентный цвет;
- аватар картинкой (PNG, JPG, WEBP, GIF до 512 КБ) или значком из набора;
- стикеры: свои картинки до 256 КБ, до 80 штук в наборе;
- темы, масштаб шрифта, звуки и уведомления — настройки хранятся на сервере.

**Интеграции и установка** — мост в Matrix: сообщения канала уходят в комнату и забираются
из неё; установка как PWA.

**Десктоп-оболочка Arc 1.4.2** — Electron-приложение для Windows с автообновлением: значок в трее
с меню (Открыть / Проверить обновления / Выход), сворачивание в трей по крестику, бейдж
непрочитанных (overlay-точка на иконке, подсказка в трее, мигание в панели задач), версия
в заголовке окна. Установщик `Arc-Setup-1.4.2.exe` обновляется сам; в настройках
десктопа есть кнопка «Проверить обновления». Ярлык на рабочем столе и папка в «Пуске»
называются `Arc`.

## Как это устроено

Cloudflare Worker + один Durable Object `ChatHub`. Воркер раздаёт статику и маршруты,
а состояние — аккаунты, каналы, история, друзья, настройки — лежит в SQLite-хранилище
Durable Object, поэтому переживает перезапуск и передеплой.

| Путь | Что это |
| --- | --- |
| `cloudflare/src/index.js` | маршруты воркера: `/api/register`, `/api/login`, `/api/media`, `/api/purge-orphans`, `/ws`, `/health`, `/avatar/*`, `/sticker/*`, `/media/*`, `/updates/*.exe`, статика |
| `cloudflare/src/hub.js` | Durable Object `ChatHub`: аккаунты, каналы, ЛС, друзья, голос, история, реакции, поиск, Web Push |
| `cloudflare/src/matrix.js` | мост в Matrix: отправка сообщений и `/sync` |
| `cloudflare/public/` | клиент `index.html`, PWA (`sw.js` с обработчиками `push`/`notificationclick`, `manifest.webmanifest`, иконки), `updates/` с частями exe и `latest.yml`, `download/Arc.apk` |
| `cloudflare/desktop/` | Electron-обёртка: `main.js`, `preload.js`, сборка NSIS |
| `cloudflare/mobile/` | Android-приложение на Capacitor: интерфейс вшит внутрь APK |
| `cloudflare/test-*.mjs` | тесты: протокол, клиент, сквозной сценарий, права владельца, CORS, мобильная сборка |

Обмен по WebSocket (`/ws`) — JSON, тип события задаёт поле `t`. Например,
`{"t":"join","room":"obshiy"}` и `{"t":"msg","room":"obshiy","text":"привет"}`:

- клиент → сервер: `join`, `dm_open`, `msg` (с полями `replyTo` и `mediaId`), `msg_react`,
  `search_messages`, `typing`, `ping`, `friend_add`, `friend_accept`, `friend_remove`, `dm_delete`,
  `msg_delete`, `create`, `channel_delete`, `voice_join`, `voice_leave`, `voice_mute`,
  `voice_screen`, `rtc`, `settings_update`, `profile_update`, `avatar_upload`, `avatar_delete`,
  `sticker_add`, `sticker_delete`, `search_users`, `user_card`, `password_change`, `logout_all`,
  `account_delete`, `logout`, `push_subscribe`, `push_unsubscribe`, `matrix_get`, `matrix_set`,
  `matrix_test`, `matrix_pull`;
- сервер → клиент: `hello` (с `version` и `pushKey`), `channels`, `channel_created`, `history`,
  `msg`, `msg_delete`, `msg_reaction`, `search_results`, `typing`, `presence`, `friends`,
  `dm_list`, `voice_state`, `rtc`, `pong`, `error`, `notice`, `logged_out`, `profile`,
  `profile_changed`, `settings`, `avatar_changed`, `sticker_pack`, `matrix_state`,
  `user_search`, `user_card`, `account_deleted`.

Поля и формы ответов:

- `replyTo` — id сообщения-оригинала; сервер кладёт снимок `reply: { id, author, text, sticker }`,
  чтобы цитата не зависела от истории;
- `msg_react { room, id, emoji }` → всем в комнате `msg_reaction { room, id, reactions }`,
  где `reactions` вида `{ "🔥": ["anna", "boris"] }`; повторная реакция тем же эмодзи снимается;
- `search_messages { q, room? }` → `search_results { q, hits }`, `hits` — `[{ room, id, author, text, ts }]`
  (от 2 символов, до 40 попаданий, только каналы и свои лички);
- `push_subscribe` / `push_unsubscribe` — подписка на Web Push; `hello.pushKey` — публичный
  VAPID-ключ, `hello.version` — версия сервера (сейчас `"1.4.2"`);
- картинки идут не по WebSocket, а по HTTP: `POST /api/media` (заголовок `x-token`, сырые байты
  до 2,5 МБ, проверка сигнатуры PNG/JPEG/WEBP/GIF) отвечает `{ id, url, mime, size }`, а
  `GET /media/<id>` отдаёт файл с `cache-control: public, max-age=31536000, immutable`.
  В сообщении `mediaId` превращается в поле `media`; сервер проверяет автора загрузки,
  поэтому прикрепить чужое вложение нельзя.

## Запуск и деплой

Локально, из папки `cloudflare/`:

```bat
node node_modules/wrangler/bin/wrangler.js dev
```

Wrangler напечатает локальный адрес (по умолчанию порт 8787). Запускать нужно именно так:
в локальном `node_modules` лежит полный wrangler, а системный `npx wrangler` — ограниченный шим.

Деплой, обновление и полный сброс данных — в [`cloudflare/ДЕПЛОЙ.md`](cloudflare/ДЕПЛОЙ.md).

Electron-сборка, из папки `cloudflare/desktop/`:

```bat
npm install
npm start
npm run build
```

`npm start` запускает оболочку без сборки, `npm run build` собирает установщик NSIS в `dist/`.
Текущая версия оболочки — 1.4.2: готовый установщик `dist/Arc-Setup-1.4.2.exe`
(121 656 750 байт), его части — в `cloudflare/public/updates/parts/`, `latest.yml` и
`parts/manifest.json` согласованы.
Автообновление берёт `latest.yml` из `/updates/`: установщик порезан на части, а воркер склеивает
их в один поток при скачивании. Порядок выпуска новой версии описан в `cloudflare/ДЕПЛОЙ.md`.

## Android-приложение

Готовый APK: **https://rust-messenger.sg530507.workers.dev/download/Arc.apk** (кнопка «Скачать APK» есть и в настройках приложения, раздел «Аккаунт»).

Сборка из папки `cloudflare/mobile/`: интерфейс берётся из `cloudflare/public/index.html` и вшивается в APK скриптом, адрес сервера подставляется отдельно.

```bat
npx cap copy android
cd android && gradlew.bat assembleRelease
```

Нужны JDK 21 и Android SDK (build-tools 36). Параметры ключа подписи лежат в `android/keystore.properties` — этот файл и сам `.keystore` в репозиторий не попадают.

## Безопасность

- Пароли: PBKDF2-SHA256, 12 000 итераций, соль у каждого своя. Старые SHA-256-хэши
  переводятся на PBKDF2 при успешном входе.
- Токены: случайные, живут 90 дней, не больше 20 на аккаунт. Выход гасит токен на сервере;
  смена пароля и «выйти на всех устройствах» гасят остальные.
- Перебор пароля: 10 неудачных попыток за 5 минут с одного адреса → 429 с паузой;
  счётчики хранятся в Durable Object и переживают перезапуск.
- Приватность: «личка только от друзей» и «невидимка» соблюдаются на сервере; список друзей
  не рассылается всем; поиск людей можно ограничить друзьями.
- Вложения: сервер проверяет сигнатуру файла (PNG/JPEG/WEBP/GIF) и автора загрузки —
  прикрепить чужое вложение нельзя; размер ограничен 2,5 МБ.
- Заголовки страницы: `x-content-type-options: nosniff`, `referrer-policy: no-referrer`,
  `x-frame-options: DENY`, `permissions-policy: camera=(), geolocation=(), microphone=(self)`.
- Трафик идёт по HTTPS Cloudflare. Сквозного шифрования нет: сервер видит сообщения.

## Ограничения

- Всё состояние — один JSON в Durable Object: он перезаписывается целиком, и этот же объект
  обслуживает все HTTP-запросы и WebSocket. Для друзей нормально, для тысяч пользователей нет.
- История канала ограничена 300 сообщениями.
- Вложения — только картинки (аватары 512 КБ, стикеры 256 КБ, сообщения PNG/JPEG/WEBP/GIF
  до 2,5 МБ); произвольные файлы, видео и голосовые пока не поддерживаются.
- Web Push приходит пустым (без текста): текст сообщения остаётся на сервере, а уведомление
  показывает только «новое сообщение».
- Голос: сервер только сводит собеседников, звук идёт напрямую. За строгим NAT или мобильным
  интернетом может понадобиться TURN-сервер.
