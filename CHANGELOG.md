# Что нового в Arc

Правило проекта: **версия меняется только при масштабных изменениях.** Мелкие правки —
тексты, подсказки, стили, исправления багов — выкладываются на боевой сервер без смены версии
и копятся в разделе «Не выпущено», чтобы попасть в следующий крупный релиз.

## Как это работает на практике

| | Крупное обновление | Мелкая правка |
| --- | --- | --- |
| Версия (`APP_VERSION`, `package.json`, `versionCode`) | меняется | не меняется |
| Service worker | новый `arc-shell-vN` | новый `arc-shell-vN` |
| Тесты | полный прогон | только затронутые |
| Деплой на сайт | да | да |
| APK | пересобирается | **не пересобирается** — правка ждёт релиза |
| Установщик Windows | пересобирается только если менялась оболочка | не пересобирается |
| GitHub-релиз | новый тег и файлы | без нового релиза |

Почему так: сайт и Windows-приложение открывают живой сервер и получают правки сразу
(оболочка Windows тоже грузит сайт, а не вшитый интерфейс). Вшитый интерфейс есть только
в APK, поэтому всё критичное для телефона копится до крупного релиза. Исключение — поломка,
без которой мобильное приложение не работает: тогда собираем APK вне графика.

## Что считается масштабным изменением

- новый раздел или сценарий (звонки, приватные каналы, приглашения ссылкой, знакомство);
- изменение протокола или модели данных, затрагивающее клиент и сервер;
- заметное изменение интерфейса, которое стоит показать в релизе;
- критичная правка, без которой мобильное приложение не работает.

## 1.6.0 — знакомство, статистика и приглашения

- **экран знакомства**: пока ничего не открыто, показывается приветствие с кнопками
  «Открыть демо-канал», «Добавить друга», «Создать канал» и мини-превью канала;
- **демо-канал**: при регистрации создаётся личный канал «Добро пожаловать» с экскурсией
  от Arc; его можно удалить, переименовать или позвать друзей;
- **счётчики в «Управлении»**: пользователи, сообщения, каналы, личные чаты, вложения,
  новые регистрации по дням, коды, сотрудники, баны и дата копии;
- **приглашение в канал ссылкой**: `.../?join=КОД` в панели канала, вход по ссылке,
  обновление и отключение ссылки, код видит только создатель;
- последний открытый канал запоминается, после перезагрузки человек возвращается в него.

Версия 1.6.0 обновлялась на месте дважды (сначала знакомство и статистика, затем ссылки):
новых тегов не появлялось, APK и релиз заменялись в рамках той же версии.

## 1.5.0 — приватные каналы

- каналы стали приватными: видны только создателю и тем, кого он позвал;
- панель канала: участники, приглашение друзей, переименование, выход и удаление;
- список каналов у каждого свой; всё в канале уходит только участникам;

- личные сообщения стали основой: они идут первыми в списке.
