# Как начать зарабатывать на разработке

Практический план на первую неделю. Цель — не «стать фрилансером», а получить
первую оплату за понятную услугу.

## Что уже готово в этом репозитории

- **Портфолио**: `/portfolio/` на сайте — услуги, цены, кейс Arc, два демо.
- **Демо-лендинг кофейни**: `/demo/coffee/` — пример работы за 15–25 тыс. ₽.
- **Демо Telegram Mini App записи**: `/demo/booking/` — пример работы за 30–60 тыс. ₽.
- **Тексты заявок**: `proposals.md`.
- **Услуги и цены**: `offer.md`.
- **Бриф**: `brief.md`.
- **Договор**: `contract.md`.

## Шаг 0. Заполните контакты (10 минут)

Откройте `cloudflare/public/portfolio/index.html`, найдите в конце скрипта:

```js
const PROFILE = {
  name: 'Ваше имя',
  brand: 'Arc Dev',
  telegram: 'your_telegram',   // ник без @
  email: 'you@example.com',
  github: 'setfators',
  arc: 'https://rust-messenger.sg530507.workers.dev/',
};
```

Впишите свои данные. Пока стоит `your_telegram`, форма открывает почту вместо
Telegram — это заметно клиенту.

Затем пересоберите и выложите сайт:

```powershell
cd cloudflare
npm run deploy
```

Проверьте:
- `https://rust-messenger.sg530507.workers.dev/portfolio/`
- `.../demo/coffee/`
- `.../demo/booking/`

## Шаг 1. Легализуйте доход (30 минут)

1. Установите приложение «Мой налог» и зарегистрируйтесь как самозанятый.
2. Привяжите карту.
3. Первый чек формируется за 1 минуту: сумма, назначение «Разработка сайта».

Это даёт 4–6 % налога и возможность работать с юрлицами. Без самозанятости
крупные клиенты часто отказываются.

## Шаг 2. Соберите профили (2 часа)

- **Kwork** — 2 карточки: лендинг и Telegram Mini App. Стартовая цена ниже
  рынка на 20 %, чтобы получить первые 3–5 отзывов.
- **FL.ru / Habr Freelance** — заполнить профиль, добавить портфолио.
- **Авито** — объявление «Сайт для бизнеса под ключ» по Иркутску.
- **Telegram** — ник для работы, описание: «Сайты и Telegram-приложения для
  малого бизнеса. Портфолио: ссылка».
- **GitHub** — закрепить репозиторий Arc, добавить ссылку на сайт.

## Шаг 3. Ежедневный ритм (будни)

- 10 откликов на Kwork/FL.ru — утром.
- 10 холодных сообщений местному бизнесу — днём.
- Ответы на входящие — в течение часа.
- Вечером: 10 минут на разбор, какие сообщения дали ответы.

Первые 3–7 дней могут не дать денег. Это нормально: вы строите воронку.
Первый заказ обычно приходит на 30–60-м касании.

## Шаг 4. Первый клиент

Цель — не заработать максимум, а получить отзыв и кейс. Возьмите один
проект за 10–15 тыс. ₽, сделайте чуть лучше ожиданий, попросите отзыв
и разрешение показать работу.

После этого поднимайте цену: следующий лендинг — 18–20 тыс. ₽,
мини-приложение — 35–40 тыс. ₽.

## Шаг 5. Что говорить про Arc

> Это мой проект: мессенджер с голосом, демонстрацией экрана, приложениями
> для Windows и Android. Делал сам, включая сервер и обновления. Сайт для
> вашего бизнеса — гораздо проще, поэтому сделаю быстро и аккуратно.

Ссылка на живой Arc и GitHub — в портфолио. Не прячьте код: для клиента это
доказательство, что вы умеете доводить до конца.

## Куда ещё стучаться

- местные бизнес-чаты Иркутска и Telegram-каналы с заказами;
- Авито «Услуги» → «Разработка сайтов»;
- 2ГИС: компании без сайта — холодные сообщения;
- профильные чаты: «Фриланс», «Веб-разработка», «Заказы на дизайн/код»;
- знакомые: один пост в личных соцсетях «делаю сайты, вот портфолио» часто
  даёт первый заказ быстрее холодных рассылок.

## Экономия на ИИ

- Одна задача — один заход: «сделай страницу X с блоками Y, проверь в Chrome».
- Не просите «сделай красиво» без критериев: это бесконечные итерации.
- Черновики и тексты сначала сами, ИИ — для кода и проверки.
- Не пополняйте баланс «на будущее»: пополняйте под конкретный оплаченный заказ.
- Первые 10–20 тыс. ₽ с заказов держите как буфер на хостинг, домен и налоги.

## Чек-лист перед первым откликом

- [ ] контакты в портфолио заменены;
- [ ] сайт и демо открываются на телефоне;
- [ ] в портфолио есть ссылка на Arc и GitHub;
- [ ] самозанятость оформлена;
- [ ] тексты заявок сохранены в заметки;
- [ ] в календаре 2 часа в день на заявки;
- [ ] цена первого проекта определена заранее.
